# CHECK POINT

Багатосторінковий food-сайт на Astro 7: чорний фон з контурними ілюстраціями, жовті кнопки, великі фотографії їжі, піца, бургери, салати та комбо.

## Запуск

`npm install`

`npm run dev`

## Збірка

`npm run build`

Статичний результат: `dist/`.

## Сторінки та функції

Головна, меню, сторінки страв і комбо, про нас, доставка, контакти, відгуки, статус оплати, конфіденційність, 404.

Пошук і категорії меню, обране та кошик (drawer/bottom-sheet на Vaul) з локальним збереженням. Оплата через Paymock: рахунок створюється через проксі `/paymock-api` (див. `astro.config.mjs`), сторінка повернення перевіряє статус інвойсу.

## Тести оплати

Проєкт Paymock: CHECK POINT. На сторінці оплати Paymock доступні дії платіжника (успішно / відмова / прострочення) — вони змінюють статус інвойсу, який сайт підхоплює на `/payment/`.

## Деплой на Cloudflare Pages

- Фреймворк: Astro, білд `npm run build`, вихідна папка `dist/`
- `wrangler.toml` — конфіг Pages
- `functions/paymock-api/[[path]].ts` — Pages Function, проксі до Paymock API (замість dev-проксі Vite, який працює тільки локально)
- `public/_headers` — базові security-заголовки
- У налаштуваннях Pages додай змінну середовища `PAYMOCK_TOKEN` (токен проєкту Paymock) — тоді токен не треба тримати в бандлі
